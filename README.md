# Internal Code Review Assistant

An automated code review assistant designed to analyze code changes, identify potential issues, and provide actionable suggestions to developers.

## Project Overview

The Internal Code Review Assistant helps developers review code changes using deterministic code-pattern checks. It analyzes uploaded Git diff files and generates suggestions to improve code quality.

## Key Features

- Upload `.diff`, `.patch`, and `.txt` files.
- Parse code changes.
- Identify potential code issues.
- Analyze changes using predefined rules.
- Generate suggested fixes.
- Keep humans in control of accepting or rejecting suggestions.

## Technology Stack

- Python
- Flask
- HTML and CSS
- Git and GitHub

## How It Works

1. Upload a Git diff file.
2. Parse the changed files and lines.
3. Analyze changes using predefined rules.
4. Review generated suggestions.
5. Accept or reject suggestions.
